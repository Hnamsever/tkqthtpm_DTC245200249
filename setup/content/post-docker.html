Docker Compose giúp dựng toàn bộ môi trường WordPress chỉ với một lệnh. Trong bài này mình chia sẻ cách kết hợp WordPress, MySQL và phpMyAdmin.

Các thành phần

  • MySQL 8 – lưu trữ dữ liệu
  • WordPress – CMS + trang admin quản lý nội dung
  • phpMyAdmin – quản trị cơ sở dữ liệu qua web

Khởi chạy

docker compose up -d
docker compose --profile setup run --rm wpcli

Sau vài phút, website đã sẵn sàng với theme Astra được cài trực tiếp từ kho theme WordPress.org.
